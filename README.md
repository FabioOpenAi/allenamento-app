# Allenamento

Piccola app web (pagina installabile sulla Home dello smartphone) per seguire una scheda di allenamento un esercizio alla volta, registrare un video dell'ultima serie, annotare kg e ripetizioni e inviare tutto al proprio allenatore con il foglio di condivisione del telefono.

- Nessun dato viene inviato a server: scheda, video e resoconti restano sul telefono (archivio del browser).
- La scheda si carica da un file `.json` (non incluso in questo archivio).
